## Overview

Dark Node.js–inspired landing for `@undermuz/use-form`: leaf-green accents, Open Sans, soft green glow. Content is composed with `@undermuz/react-page-builder`; edit mode is DEV-only.

## Style Foundations

- **Visual style:** modern, minimal, spacious, dark-first (nodejs.org)
- **Typography scale:** desktop-first expressive scale
- **Typography fonts:** primary=Open Sans, display=Open Sans, mono=system mono
- **Color palette:** Node green primary, soft green secondary, charcoal surface
- **Spacing scale:** comfortable density mode

## Colors

- **Primary (#5FA04E):** CTAs, pills, accents.
- **Secondary (#84BA64):** Labels and glow.
- **Surface (#0D1117):** Page background.
- **Surface elevated (#161B22):** Panels / code window.
- **Text (#FFFFFF) / muted (#B9BBBE):** Copy hierarchy.
- **Border / glass:** Translucent white overlays.
